# Jewandre Practice

Hands-on practice material for the **Industry Practices Bootcamp: Blazor, C# & SQL**.

Planned contents:

- `src/` – a small Blazor + C# app with deliberate bugs and code smells to fix (Modules 2–4)
- `sql/` – sample schema, seed data and report stored procedures to review and tune (Module 5)
- Git exercises – branches, a planned merge conflict, a rebase and a revert (Module 7)
- `.github/workflows/` – CI that builds and tests every pull request (Module 6)
